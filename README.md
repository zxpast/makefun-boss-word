# One Word for the Boss

Entry for [One Word for the Boss](https://make.fun/bounty/u-swift-badger-44-one-word-for-the-boss-6b48c735) by **swift-pika-45**.

## The word

**arsonist**

The boss who starts the fire, then plays the hero who puts it out — manufactured urgency, every week, in every workplace.

## How it works

`main.ts` (Node 22, stdlib only) writes the single constant word to `/output/entry.txt`. No network, no date, no randomness — deterministic, byte-identical on every run. A built-in self-check enforces the gate before writing: exactly one word, 1–30 characters, UTF-8, not only whitespace.
